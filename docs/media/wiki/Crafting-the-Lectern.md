# Crafting

All Scribe items are crafted at a normal grid. The Lectern, Notebook, and Tablets are ungated; the
Clockmaker's Notebook is gated to the Clockmaker character class (see below).

## Lectern

Craft the Lectern at a **3×3 crafting grid** using the following layout:

![Lectern crafting recipe](https://i.imgur.com/27NBoci.png)

```
[ Feather ]  [ Parchment ]  [ Leather ]
[ Plank   ]  [ Plank     ]  [ Plank   ]
[ Ink bowl]  [ Plank     ]  [ Nails   ]
```

Produces **1 Lectern**.

- The bowl must be **fired** (unfired clay bowls do not work) and must contain at least **1 litre of black dye**. The bowl is consumed in the craft.
- Any wood plank type works for all four plank slots.
- Any metal nails and strips work (copper, tin bronze, bismuth bronze, iron, etc.).

## Notebook

Craft the Notebook on a **3×2 area** of the grid, using the same writing-set vocabulary as the Lectern:

```
[ Feather  ]  [ Parchment ]  [ Nails ]
[ Ink bowl ]  [ Leather   ]  [       ]
```

Produces **1 Notebook**.

- The bowl must be **fired** and hold at least **1 litre of black dye**, and is consumed — exactly like the Lectern.
- Any metal nails-and-strips work for the buckle.

## Clockmaker's Notebook

Craft the Clockmaker's Notebook from a finished Notebook plus a clockwork core, in a **3×1 row**:

```
[ Notebook ]  [ Temporal gear ]  [ Metal parts ]
```

Produces **1 Clockmaker's Notebook**.

- **This recipe requires the `tinkerer` trait**, which is granted by the vanilla **Clockmaker** character class. A player of another class will not see the recipe succeed. A server operator can lift this requirement world-wide — see [Clockmaker's Notebook & Timers](Clockmakers-Notebook-and-Timers#crafting-and-the-tinkerer-trait).

## Tablets

Tablets are the early-game exception: no writing set, no fired ink bowl — just clay or beeswax and a tool. Both are ungated.

### Clay Tablet

Knap a clay Tablet on a **3×3 grid** from a knife, a stick, and clay:

```
[ Knife ]  [ Clay ]  [ Clay ]
[ Stick ]  [ Clay ]  [ Clay ]
[       ]  [ Clay ]  [ Clay ]
```

Produces **1 wet Clay Tablet**.

- Takes **6 clay** total. The clay colour sets the Tablet colour — **red**, **blue**, or **fire clay** each give a matching Tablet (cosmetic only).
- The knife is a tool and takes a little durability; it is not consumed.

### Wax Tablet

Craft the reusable Wax Tablet on a **3×3 grid** from a saw, wooden planks, a stick, and beeswax:

```
[ Saw   ]  [ Plank ]  [ Plank ]
[ Stick ]  [ Wax   ]  [ Wax   ]
[       ]  [ Wax   ]  [ Wax   ]
```

Produces **1 Wax Tablet**.

- Takes **4 beeswax** and **2 planks** (any wood). The saw takes a little durability; it is not consumed.

See [Clay & Wax Tablets](Clay-and-Wax-Tablets) for the drying, re-wetting, and firing life-cycle.

## Notes

- All recipes appear in the **in-game Handbook** (H key) under each item's entry.
- Parchment is crafted from dried papyrus or hide at a crafting grid — check the in-game handbook for its recipe.
