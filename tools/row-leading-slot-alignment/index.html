Row leading-slot alignment

Every row's leading control (checkbox / Quest icon) and its name text are positioned by separate formulas today, on the Notebook surface (Read/Editor/Pinned share one path). They agree by luck, not by construction — this tool makes both formulas' outputs visible and tunable at once, plus the HUD's structurally-different (native-centered) path for comparison. Solid green/red/orange lines are where each element's geometric box centers per the formula; dashed lines are the actual rendered glyph/box center (fonts have asymmetric ascender/descender space, so these two don't automatically match even when the formulas agree numerically).

Browser text metrics ≠ Skia. This is for finding the right formula/constants, not final pixel truth — confirm in-game after.

Tablet stage (added 2026-09-07): models the tablet's cuneiform LAYOUT math exactly (CuneiformMetrics.LineHeightRatio/GlyphDrawScale/CaretHeightScale/FieldPadYScale, the checkbox/control-size decoupling from GuiDialogScribeTablet.DecorateRowStyle, and the quest-aware CheckboxAndGripTop/ItemNameLineHeight/GripInsets fix) — it does not render actual cuneiform glyph strokes (uppercase placeholder text stands in for the glyph line instead). Uses it for band-height/ checkbox-overflow/caret/padding math, not for glyph shape or spacing checks; confirm those in-game.

Name text always wraps naturally at the row-width knob below (no synthetic line-count guess) — every band/height calc is driven off the browser's own measured wrapped-text height, so shrinking the row width is how you induce and inspect real multi-line growth on any row kind. Notebook's default is the real in-game value: ScribeLayout.TasksColW at the default PixelArtSize of 600 (0.8×600 = 480px; ranges ~320–800px across the 400–1000 PixelArtSize setting). HUD's real in-game default is ScribePlayerSettings.HudRowWidth = 250px, but this knob defaults to 400px purely as this tool's preview starting point (nothing in the mod changed) — drop it to 250px to see real default-width HUD behavior, where most rows wrap.
